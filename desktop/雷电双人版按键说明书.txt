雷电·双人版  按键说明书
========================================

打开方式：双击桌面上的「雷电双人版.html」，用浏览器打开即可游玩。

【一、菜单 / 难度选择】（标题画面）
  ← / →  或  A / D        切换难度（↑ / ↓ 或 W / S 也可以）
  难度共6级：儿童、新手、简单、普通、困难、地狱
      儿童：适合5岁小朋友，敌人很少（约为新手的一半），子弹很少很慢，
            道具和关底Boss照常出现
      新手：敌人约为普通的1/4，子弹少且慢，适合入门
      简单：敌人和子弹较少
      普通：标准难度
      困难：敌人更多，弹幕更快更密
      地狱：敌人翻倍，满屏弹幕
  （难度选择会自动记住，下次打开仍然有效）
  1                          开始单人游戏
  2                          开始双人游戏

【二、1P 红色飞机】
  W / A / S / D              上 / 左 / 下 / 右 移动
  K                          放炸弹
  射击：全自动，无需按键

【三、2P 蓝色飞机】
  方向键 ↑ ← ↓ →             移动
  小键盘2  或  .（句号键）    放炸弹
  射击：全自动，无需按键

【四、暂停】
  P                          暂停 / 继续
  （答题时和“休息一下吧”画面上，游戏按键不起作用）

【五、游戏结束后】
  R                          用同样的模式和难度重新开始
  Enter                      返回标题画面（可重新选难度）

【六、道具说明 / 武器种类（参考原版雷电）】
  每个玩家的武器是分开的：屏幕左上角显示1P的武器，右上角显示2P的武器，
  第一行是主武器和等级，第二行是“+副武器 等级”。

  ◆ 主武器：P 水晶（颜色每隔约2秒在 红 → 蓝 → 绿 之间循环变化）
  P（红色）  散弹 Vulcan：子弹向前方扇形散开，等级越高子弹越多、扇面越宽，
             适合打满屏的小飞机。
  P（蓝色）  激光 Laser：集中向正前方的粗光束，单发伤害高，等级越高越粗越密，
             适合打Boss和大飞机。
  P（绿色）  穿透波 Wave：绿色的弧形能量波，会穿过敌人继续往前飞，
             一路上的每个敌人都会被打到；等级越高波越宽，4级起左右再多两道斜波。
             适合敌人排成一列或挤在一起的时候。
  主武器最高 5 级，开局是红色散弹 1 级。

  ◆ 副武器（导弹）：S 方块（字母在 H 和 M 之间交替变化，会和主武器一起自动发射）
  H（紫色）  追踪导弹 Homing：自动转弯去追最近的敌人，打不准也没关系。
             1～2级每次2发，3级起每次4发，等级越高发射越快。
  M（橙色）  核导弹 Nuke：笔直向前、越飞越快，打中后会爆炸，
             把周围一圈的敌人一起炸伤。1级单发，2～3级双发，4级四发。
  副武器最高 4 级；一开始没有副武器，要先捡到 S 方块。
  S 方块来源：大型轰炸机、每关Boss、V字队形的领头机、以及每消灭一定数量的敌机。

  ◆ 怎么换武器 / 升级（两种道具规则一样）
  吃到和自己当前武器【不同颜色/不同字母】的道具：直接换成那种武器（等级不变），不用答题；
  吃到和自己当前武器【相同颜色/相同字母】的道具：要答一道数学题，答对才升1级；
  已经是最高等级时再吃同色道具：直接加 5000 分。
  小技巧：看准道具当前的颜色再去吃，想换武器就等它变成想要的颜色。

  ◆ 其他道具
  B（绿色圆圈）炸弹 +1：放炸弹会清除全屏敌方子弹并伤害所有敌人，
              放炸弹时飞机短暂无敌
  金牌        加分

【七、血量 / 命数】
  每人3条命，每条命3点血量。
  每被敌方子弹或敌机撞到一次扣1点血，之后约0.5秒内不会再扣血。
  血量扣到0时飞机爆炸，失去一条命，并在约2秒后满血复活，复活后短暂无敌。
  阵亡后主武器和副武器都回到1级（武器种类不变），会掉落一个P道具
  （有副武器且超过1级时还会掉一个S道具），可以捡回来。
  两个玩家的命都用完时，游戏结束。
  打败关底Boss后进入下一轮，敌人会越来越强。

【八、英语填空（每关开始前）】
  每一关开始前，会出现一道英语填空题：
  上面有图片和中文意思，下面是课本里的单词或短语，少了一个字母，
  例如：🪥 刷牙  brush my t _ eth
  用键盘输入缺少的字母（大小写都可以），按 Enter 确认，Backspace 可以删除。
  答对 3 题才能开始这一关；答错了会告诉你正确答案，再换一道新题，不扣分不扣血。
  双人模式两位玩家一起答同一组题。答题时游戏是暂停的。
  题目左上角显示单词所在单元（例如“2A U6”），下方显示“已学到”哪个单元。

  词库来自 牛津上海版（上海教育出版社）五四制 二年级上册（2A）2024新版，
  共10个单元、42个词条（短语只在关键词里挖空）：
    U1  My morning      get up 起床 / brush my teeth 刷牙 / wash my face 洗脸 / have breakfast 吃早饭
    U2  My room         on the desk 在书桌上 / in the box 在盒子里 / under the bed 在床底下
    U3  On the way      by car 乘小汽车 / on foot 步行 / by bus 乘公共汽车
    U4  Playing sports  run 跑 / jump 跳 / play ping-pong 打乒乓球 / play basketball 打篮球 / play football 踢足球
    U5  In the sky      in the sky 在天空中 / star 星星 / sun 太阳 / cloud 云 / moon 月亮
    U6  In the sea      in the sea 在海里 / seahorse 海马 / dolphin 海豚 / clownfish 小丑鱼
    U7  Seasons         spring 春天 / summer 夏天 / autumn 秋天 / winter 冬天
    U8  Yummy fruit     fruit 水果 / apple 苹果 / pear 梨 / banana 香蕉 / grape 葡萄 / orange 橙子
    U9  The five senses smell 闻 / taste 尝 / touch 摸 / see 看见 / hear 听见
    U10 This is me      draw a picture 画画 / read a book 看书 / make breakfast 做早饭

  ★ 按教学进度出题（只出已经学过的单元）：
    游戏会看电脑的“今天日期”，只从开始日期在今天或之前的单元里出题。
    日期往后走（比如过了一个月），新学到的单元会自动加进来。
    默认进度表（每个单元的开始日期，9月1日开学；按班级实际进度，11月中旬学到U7，
    之后约每两周一个单元）：
      U1  9月1日     U2  9月12日    U3  9月23日    U4  10月8日    U5  10月19日
      U6  10月30日   U7  11月10日   U8  11月24日   U9  12月8日    U10 12月22日
    8月（开学前）只出 U1；寒假后（2月起）出全部单元。
    家长修改进度：用文本编辑器打开「雷电双人版.html」，搜索 SCHEDULE，
    把对应单元后面的日期（格式 '月-日'，如 '11-24'）改成孩子实际上课的日期，保存即可。
    单词表在同一文件中搜索 WORDS 可以找到，可按课本增删。

【九、数学题（吃到同色P / 同字母S道具时）】
  吃到和自己武器同颜色的P道具、或同字母的S道具时，游戏会暂停，并出现一道数学题，上面写着是1P还是2P捡到的。
  题目是二年级的：100以内加减法、2～9的表内乘法、简单的表内除法。
  用键盘输入数字，按 Enter 确认，Backspace 可以删除。
  答对：这件武器升1级，还会被表扬；
  答错：显示正确答案，这次不升级，但不会扣血。
  答题时所有子弹和敌人都会停住，不用着急。
  （换成别的颜色/字母、B炸弹和金牌都不需要答题。）

【十、防沉迷（给家长看）】
  每天最多玩 12 分钟（只计算进入关卡后的时间，答题时间也算；暂停、标题画面和
  游戏结束画面不计时）。画面上方会显示“剩余时间”，剩1分钟时会提醒。
  时间到后会出现“休息一下吧！”画面，游戏停止，刷新网页也不能继续。
  第二天会自动重新计时。

  ★ 家长解锁方法（屏幕上不会显示，请勿告诉小朋友）：
    在“休息一下吧！”画面上，按住 Shift 键不放，依次按数字键 8 8 8 8，
    然后松开 Shift，按 Enter。
    解锁后会再给 12 分钟游戏时间，游戏从刚才停下的地方继续。

【十一、苹果手机版（单人）】
  手机版是单独的一套文件（mobile 文件夹：index.html 等），只能一个人玩，
  难度、5种武器、英语填空、数学题、每天12分钟、各难度最高分都和电脑版一样。
  （手机和电脑的游戏时间、最高分各自分开记录。）
  标题画面：点“儿童 / 新手 / 简单 / 普通 / 困难 / 地狱”选难度，点“开始游戏”。
  移动：手指放在屏幕任意位置（不用按在飞机上）拖动，飞机就跟着手指移动同样的距离，
        手指不会挡住飞机；松开手指飞机停住。
  射击：全自动。
  炸弹：点右下角绿色圆形“炸弹”按钮（上面显示还剩几个）。可以一只手拖动、另一只手按炸弹。
  暂停：点右上角“❚❚”按钮，暂停画面里可以“继续游戏”或“返回标题”。
        切到别的App或锁屏时会自动暂停。
  答题：屏幕下方会出现按键。英语题点字母，数学题点数字，“⌫ 删除”改错，点“确认”提交。
  游戏结束：点“再玩一次”或“返回标题”。
  装到主屏幕：用 Safari 打开游戏网址 → 点底部“分享”按钮 → “添加到主屏幕”，
        以后从桌面图标打开就是全屏，第一次打开后断网也能玩。

  ★ 手机版家长解锁方法（屏幕上不会显示，请勿告诉小朋友）：
    在“休息一下吧！”画面上，用手指按住黄色大字“休息一下吧！”不动，约 3 秒后
    屏幕下方会出现数字键盘，输入 8 8 8 8，再点“确认”。
    输错会提示“密码不对哦”并收起键盘，需要再长按 3 秒重新输入。
    解锁后会再给 12 分钟游戏时间。

【十二、8个关卡 / 敌人 / Boss（电脑版和手机版相同）】
  一共 8 关，每关的地形、敌人和 Boss 都不一样。打完第 8 关会回到第 1 关，
  开始“第 2 轮”，敌人更硬、子弹更快更密（每过一轮都会再加强）。
    第1关 草原     　Boss：钢铁要塞　　——瞄准散射 → 旋转弹 → 环形弹幕
    第2关 海洋     　Boss：巨舰「海神号」——甲板炮塔轮流开火 → 两舷扫射并放水雷 → 环形弹幕
    第3关 沙漠     　Boss：沙漠巨蝎　　——钳子散射 → 尾巴发激光 → 带缺口的子弹墙（从缺口钻过去）
    第4关 雪原     　Boss：冰霜飞翼　　——投下会炸开的冰弹 → 翼尖螺旋弹 → 高速横扫
    第5关 城市     　Boss：雷霆双旋翼　——机枪点射 → 会拐弯的追踪火箭 → 三向螺旋弹
    第6关 火山     　Boss：熔岩巨炮　　——会炸开的熔岩弹 → 两侧激光 → 熔岩雨加中央激光
    第7关 丛林     　Boss：空中航母　　——放出战斗机 → 放出自爆机和两侧弹流 → 大环形弹幕
    第8关 太空基地 　Boss：核心母舰　　——旋转炮台弹流 → 十字旋转激光 → 花形弹幕加追踪弹
  Boss 血量剩 2/3、1/3 时会换一种攻击方式。
  激光一定会先出现“红色/紫色虚线”预警，看到虚线赶快躲开，几秒后才真正发射。

  新敌人：
    直升机   ：飞进来停住，连射三轮扇形子弹后从侧面飞走。
    自爆机   ：红色小飞机，停住闪“！”之后，朝你当时的位置猛冲过来，躲开就行。
    狙击机   ：先射出一条红色瞄准线跟着你，瞄准线开始闪烁就要马上换位置，
               然后会射出一发很快的子弹。
    浮游水雷 ：带刺的圆球慢慢飘下来，你靠近时会闪红灯，然后炸开一圈慢子弹；
               先把它打爆就安全了。
    布雷机   ：横着飞过屏幕，一路丢下水雷。
    重装炮艇 ：很厚的装甲，要打很多下；停在上方交替齐射，打爆会掉很多道具。
    分裂机   ：旋转的橙色飞行器，打爆后会分成 3 架小飞机。
    巡逻艇   ：海面上的小船，会开炮。
    战舰     ：海上的长条大船，身上有 3 座炮塔；炮塔还在时船身很硬，先打炮塔。
  （坦克会转动炮塔一直瞄着你；还有原来的战斗机、炮台、炮艇、轰炸机。）

  难度说明：
    儿童：没有自爆机和狙击机，水雷只会冒烟不会放子弹，激光预警时间更长、光束更细。
    新手：自爆机冲得慢，狙击机和水雷的预警时间更长。
    其他难度：敌人数量、子弹速度和密度按原来的难度比例变化。
